# 北京单场比分预测（Beidan Score Predictor）

一个**公开、可审计**的北京单场足球精确比分预测实验。

## 定位（诚实声明）

- **精确比分是 25 选 1 的超高方差预测，天花板约 10-12%**（历史众数基线）。
- 本项目**不声称能跑赢市场**，目标是透明地记录"按当前情报逐场推导"的方法论、预测、开奖、复盘全过程。
- 谁跟你说精确比分能"稳赢""包中"，谁就是骗子——包括我们自己。

## 核心方法

**预测基于当前实际情况，历史数据仅作参考**（用户 2026-08-11 定调）：

1. **赛前情报强制收集**：Sofascore 伤病/缺阵名单（`missingPlayers` 比全队伤病更精准）+ Open-Meteo 开球天气 + 球场（高原/草皮）
2. **逐场推导剧本**：双方当前状态 + 两回合战意 → 比赛性格 → 唯一比分
3. **SP 完全不参与预测**：比分生成、排序、选场都不看 SP；SP 只作市场资金流向的辅助参考
4. **历史数据仅作校准**：不用历史频率套当前场次，只用它判断"精确比分天花板在哪"
