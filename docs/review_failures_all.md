## 三、血写的教训（方法论层面，钉死）

1. **先筛后挑，不许直接单挑**：λ能力区间（对位修正）排除不可能 → 剩下小池
   → SP作辅助背景（有实据的比分SP高照推） → 情报只在分歧点单挑
2. **只出少数场，资金集中**：3-5场/期，一场一个比分。撒网100个比分=没有资金支持=自欺
3. **我的价值=市场盲区**：只推"市场Top3之外我有实据"的比分。跟市场共识的场次不碰——
   没把握就是0场。验证标准：命中率>市场Top1，且存在市场Top3之外的情报增量命中。
   做不到这两条，这个位置就没有存在意义。
4. **串关是回本工具，必须用**（用户8/15定）：串关把SP相乘叠赔率，单关回不了本。
   但串关只用在λ筛选+情报盲区后的少数场次上，张数按当天场次规模定：
   ≤10场推5场；≤50场出2-3张二串三串共40元；≤100场出5-6张二串三串。每张都是串关不单关。5. **汇报只报精确命中数**，方向/差一球/数学上限全部从复盘语言里删除。
6. **工具硬检查**（已修）：票单生成校验官方"销售中"；已购票单冻结只报警不改。
7. **出票按场次规模**（用户8/15定）：≤10场推5场；≤50场2-3张二串三串共40元；≤100场5-6张二串三串。串关必用（回本靠SP相乘），不单关。
