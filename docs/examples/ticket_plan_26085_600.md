# 26085期 600元五场分层串关出票单

## 出票规则

- 总预算：**600元**
- 共 **15组五场票**，每组40元
- 每组同时勾选：**2串1 + 3串1**
- 5场展开：C(5,2)=10组二串，C(5,3)=10组三串，共20注
- **每注1倍、2元**：20×2=40元/组；15×40=600元
- 每组固定结构：**3个相对强项 + 1个中档项 + 1个有实际依据的搏点**
- “强”只表示当前情报相对完整、剧本更清楚，不是包中；“搏”不是乱猜，只是精确比分波动更大
- SP不参与比分和强弱分层，仅在出票后用于奖金结算

## 柜台操作

每一组五场都选择单一比分，然后同时勾选 **2串1、3串1**，倍数填 **1倍**，该组金额应显示 **40元**。15组总金额应显示 **600元**。

若终端不能在同一张票同时打印两种过关方式，就把每组拆成：

- 同样5场的2串1：10注×2元＝20元
- 同样5场的3串1：10注×2元＝20元

纸面会变成30张，但仍是15个五场组合，预算仍为600元，不能加倍。
