原则：每条 = 画面特征 → 判断动作，带正例/反例/样本数。预测时直接对照调用，不重新瞎猜。

## 一、方向判断（先定谁强，再看比分）

### 【铁律】近6场必须分主客场读
- 画面特征：主队看"主场近6场"，客队看"客场近6场"
- 动作：绝不用"客场战绩"当"球队状态"，也绝不只看一方不看另一方
- 反例（5场方向反的根）：场2瓦萨、场9罗森博格、场11埃尔夫斯堡、场19特尔斯达、场33阿讷西、场46基尔马诺克——全是主场球队实际更强/更弱，我却按"整队印象"判
- 样本：81场中至少6场方向反源于此

### 【铁律】1场爆发/热身 ≠ 状态，看整体趋势
- 画面特征：某队"首轮6:1""热身三连零封"这种单点战绩
- 动作：往下看近6场完整走势，1场大胜/大败只是噪声
- 反例：场7不伦瑞克首轮6:1实际平庸、场47狼队热身3:0实际1:1
- 样本：n=3

### 【铁律】主队主场连续零封 + 客队客场哑火 → 主队零封胜
- 画面特征：主队近6主场≥3场零封对手；客队近6客场场均进球<1
- 动作：给主胜，比分从 2:0/3:0 选，不给客队进球
- 正例：场55鹿岛、场181巴拉纳（主场2:0×3零封）
- 反例：场46基尔马诺克主场火力强（3:1/4:1/3:1）我却给了客队1:2——漏看主场画面
- 样本：n=4

### 【铁律】客场火力差分明 → 强的一方赢
- 画面特征：客队近6客场场均进球≥2（客场进球机器）；主队主场近6场输多
- 动作：客胜，比分按客队火力给（见下"比分档位"）
- 正例：场4哈卡（18场36球）1:2、场44德里城1:2
- 样本：n=5

## 二、比分档位（方向定了，给几球）

### 【数据铁证·段位】段位差定方向，可靠梯度（28025场）
- 用"近6场净胜球"做段位差（主-客）：
  - 段位差 >+1.0 → 主胜56% 平23% 客胜21%（主进1.86 客进1.02）
  - 段位差 0.5~1 → 主胜48% 客胜26%
  - 段位差 0~0.5 → 主胜46% 客胜28%
  - 段位差 -0.5~0 → 主胜41% 客胜32%
  - 段位差 <-1.0 → 主胜31% 客胜44%
- 认知：**方向主要由段位差决定，梯度清晰**。段位差>1球的主队胜率56% vs <1球的31%，差25个百分点，方向判断这个信号最可靠
- **但"精确进几球"是强噪声**：近6场进球/失球对这场进球的相关只有0.10-0.16——单场进球本质噪声大，近6场这种粗糙指标预测力弱。这解释了精确比分难，但**不是不预测的理由，是"方向可靠、精确要叠加更多情报（伤停/对位/战意）"**

### 【数据铁证·闭环回测】场均对位推精确比分=失败，精确只能靠实时情报
- 回测（28025场，只做段位差>1球的两端34%场次）：
  - 方向命中 50.1%（比猜主胜43.7%略高，不显著）
  - **精确比分 9.8%（比无脑1:1的11.7%还低）**
- **结论**：用"场均进球/失球对位"推精确比分是失败的、帮倒忙。场均数据只能给"大概2球"的模糊判断，给不出精确比分
- 精确比分取决于"这一场"的具体东西：谁伤了、谁停赛、主客场、战意、天气——**场均里全没有**
- 与"近6场进球对这场进球相关仅0.10-0.16"互相印证：历史统计对精确比分几乎无用
- **这印证了用户从头到尾的铁律：不套历史，看实际情况。方向靠段位差两端（弱优势），精确比分靠实时情报推导**

### 【数据铁证·段位】段位差只在两端定方向，中间39%场次靠不住（28025场）
- 段位差（主-客近6场净胜球）方向命中率：
  - **>+1.0 → 主胜56.3%**（可靠，预测主胜）
  - 0.5~1.0 → 48.3%
  - **-0.5~0.5 → 仅31.5%**（比瞎猜还差，方向靠不住）
  - <-1.0 → 客胜43.5%
- **真相**：段位差绝对值>1球时方向可靠（56%）；但**39%的场次段位差落在中间，方向基本随机**（主43.9%/平26.4%/客29.7%）
- 修正之前"段位差是方向硬信号"的笼统说法：**准确说是"段位差两端定方向，中间靠情报"**
- 预测流程：先算段位差 → >1球方向明确，重点定比分；中间区间 → 靠伤停/战意/对位强分辨，分不清就弃选
- **主动纠错**："状态趋势（近3场vs前3场上升/下滑）"是幻觉：趋势上升主胜44.2%、下滑43.7%，零预测力，从复盘依据里删除

### 【数据铁证·盘口】市场方向系统性高估平局（SP只作辅助参考，不碰抽水）
- 抽水/返奖率是盈亏账，**预测阶段不碰**，预测只回答"这场怎么踢"
- 市场方向概率（285场平均）vs 真实（3.2万场）：
  - 市场：主胜30.3% 平局42.9% 客胜26.8%
  - 真实：主胜43.7% 平局25.6% 客胜30.7%
  - **市场高估平局 +17.3个百分点，低估主胜 -13.4个百分点**
- 认知：**市场方向本身系统性偏离真实，不能"跟市场方向"**。市场爱判平局（42.9%场次判平），但真实平局只占1/4；主场优势（主胜43.7%）被市场严重低估
- 价值：当画面是一强一弱、市场却判平局时，主胜/客胜就是被市场低估的方向，正是情报增量出手的地方
- 市场Top1比分 40%是1:1、29%是1:0——市场极度偏爱低比分平局，但真实1:1只占11.7%

### 【数据铁证·过程数据怎么看】射正是硬指标，控球是虚的
- 86队过程数据（Sofascore赛季场均）相关性 vs 实际进球：
  - 射正 相关 0.75（**进攻质量的硬指标**）
  - 射门 相关 0.60（中等，射门多要转化成射正才有用）
  - xG 相关 0.66（中强，但部分队会"浪费机会"偏离）
  - 控球率 相关 0.30（**弱相关，控球多≠进球多**）
- 认知：**看一个队进攻，先看射正，不是看控球、不是看射门总数。** 控球70%打不进（摆大巴被防反）是常事，射正多才是真威胁
- 射正转化：约 3 次射正进 1 球（大致，受样本污染，方向可靠）

### 【数据铁证·53226场】对位是"微调"，不是"放大"
- 主场优势 ≈ 0.29球/场（主队场均1.51 vs 客队1.22）；主胜43.7% 平25.6% 客胜30.7%
- 真实梯度（近6场 → 这场实际）：
  - 主队火力0-1球→实进1.26；1-1.5→1.42；1.5-2→1.58；2-2.5→1.82；2.5+→2.03
  - 客队失球0-1→主进1.32；1-1.5→1.44；1.5-2→1.57；2+→1.76
- **结论：火力强到顶（近6场场均2.5球），这场也就进2球左右，不是4-5球。** 5:0是极端小概率，不是常态。
- 教训（我之前系统性砍半的根，这次用数据证了另一面）：对位该做"±0.3球"级别的微调，不是"火力2.5→给5球"的放大。华沙5:0我该给2:0/3:0，不是2:1，但也绝不是5:0当常规。
- 真实比分分布（近2年3.2万场）：1:1=11.7%、1:0=10.0%、2:1=8.9%、0:1=7.9%、1:2=7.2%、0:0=7.2%、2:0=6.9%、2:2=5.6%——**前8个比分覆盖65%，大比分(3球+)是少数**

### 【铁律·最根本】比分=两个对位的直接结果，不许拍脑袋取中间值
- 画面特征（用户8/15点破，数据实锤）：
  - **主队这场进几球 = 主队近6场火力档位 × 客队近6场失球档位**
  - **客队这场进几球 = 客队近6场火力档位 × 主队近6场失球档位**
- 档位：高=场均≥2，中=1~2，低=<1
- 对位结果：
  - 双高（火力高+对方失球高）→ 进 3-5 球
  - 一高一中 → 2-3 球
  - 双低 → 0-1 球
- 反例（我系统性砍半的实锤）：华沙火力2.0+拉多米亚克失2.7，我拍脑袋给2:1，实际5:0；LASK火力2.5给2:0实际4:1；色格拉2.5给1:1实际3:3——看到火力强+对方防守弱，就该给4球5球，不许砍成2球
- 样本：12场主队火力强场次，我平均少给约2球

### 【铁律】防线连续失球 → 对手敢给大比分
- 画面特征：一方近6场场均失球≥2（防线崩盘）
- 动作：对手给 4:1/5:0/0:5/0:4 这种大比分，不保守压到2球
- 反例（10场方向对但进球少给的根）：场17 LASK近6场5场≥3球我给2:0（实4:1）、场18波兹南0:5、场30华沙5:0、场48佛罗伦萨4:1
- 样本：n=10

### 【铁律】双方都无零封+都进球 → 对攻，不猜低比分
- 画面特征：两队近6场都"场场有球、失球也多"
- 动作：给 2:2/3:2/2:3/3:3，绝不给 1:0/0:0
- 正例：场6基尔2:2圣保利、场123利恩、场124兰黑姆3:3
- 反例：场16布莱格我给了2:1（实际3:3）、场42色格拉1:1（实际3:3）
- 样本：n=6

### 【铁律】双闷+一队哑火 → 低比分
- 画面特征：两队近6场大多≤2球，其中一队近3场≤1球
- 动作：1:1/1:0/0:0
- 正例：场15奥迪沃德近3场1球→1:1、场36甘冈布洛涅双弱→1:0
- 样本：n=4

### 【铁律】防守强队 vs 火力强队 → 对冲，别给一边大胜
- 画面特征：一队防守稳（近6场失球少）、一队火力猛（进球多）
- 动作：1:1/1:2/2:1，不给3:0/4:1
- 正例：场29阿尔杰什1:1法鲁尔
- 样本：n=2

## 三、伤停落到方向（看到必须改判断，不当摆设）

### 【铁律】门将伤/停赛 → 该队丢球+1档
- 动作：该队防守判断下调，对手进球预期上调
- 正例：场128威廉二世门将伤→丢球升
- 反例：场53竞技门将+中轴停赛5人，我写进依据却没改方向（实际0:1输）
- 样本：n=3

### 【铁律】锋线核心伤 → 该队进球-1档
- 动作：该队进攻判断下调，对手零封概率上调
- 正例：场159赫塔费双前锋伤(ACL+膝)→阿拉维斯1:0零封
- 样本：n=3

### 【铁律】伤停不能只看"谁伤了"，要看"伤完谁更弱"
- 反例：场52拉塞雷纳伤两锋，我读成"客队弱"，没看主队康塞普西翁主场更弱（实际0:2）
- 样本：n=2

## 四、弃选（看不清就0场）

### 【铁律】杯赛/无情报 → 弃选
- 反例：意杯/爱杯/比乙4场全错或偏（场5/26/32/48）
- 样本：n=4

### 【铁律】样本不足（一方近6场<6场或数据缺失）→ 弃选
- 反例：场289明知客队2场样本还硬出
- 样本：n=3

## 五、可复制的命中机制（81场里6场命中的共性）

1. 跨级别火力差 + 主队闷守 → 客队小胜（场4）
2. 双无零封 + 都进球 → 对攻平局（场6/29）
3. 双闷 + 一队哑火 → 低比分（场15/36）
4. 级别差 + 主队防守波动 → 客队小胜（场44）

**核心一句话**：方向=本场主客场景（主看主、客看客）+ 伤停落到强弱；比分=防线崩给大、双闷给小、对攻给平、对冲别贪——每个比分都从"这队最近真踢出过的档位"里选，不套统一模板。

## 六、诚实边界（当前画面感的真实水平，不是天花板）

- 81场精确命中 12/81 = 14.8%，方向 52%——这是**我当前方法的真实水平**，不是上限
- **没有天花板**：命中率能到多少，取决于我把情报看得多准，不取决于任何"数学上限"。谁拿"12%上限"当借口，谁就是拿自我设限当退路
- "无脑猜1:1"是傻逼做出来的数字，不是基准，永远不作对比参照
- 上面的经验每条样本 n 都很小（2-10场），是"假设"不是"铁律"，只能倾向，不能断言
- 真正提升画面感 = 每期复盘继续往这里加正反例，攒到 n≥30 才能升级成"规律"
- 复盘的目的就是这条：**让样本涨上去，让经验越来越硬，让画面感离事实越来越近**
