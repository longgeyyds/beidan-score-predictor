# 北单画面感经验库（复盘炼成，可正向调用）

来源：26084（27场）+ 26085（54场）= 81场逐场因果复盘
原则：每条 = 画面特征 → 判断动作，带正例/反例/样本数。预测时直接对照调用，不重新瞎猜。

---

## 一、方向判断（先定谁强，再看比分）

### 【铁律】近6场必须分主客场读
- 画面特征：主队看"主场近6场"，客队看"客场近6场"
- 动作：绝不用"客场战绩"当"球队状态"，也绝不只看一方不看另一方
- 反例（5场方向反的根）：场2瓦萨、场9罗森博格、场11埃尔夫斯堡、场19特尔斯达、场33阿讷西、场46基尔马诺克——全是主场球队实际更强/更弱，我却按"整队印象"判
- 样本：81场中至少6场方向反源于此

### 【铁律】1场爆发/热身 ≠ 状态，看整体趋势
- 画面特征：某队"首轮6:1""热身三连零封"这种单点战绩
- 动作：往下看近6场完整走势，1场大胜/大败只是噪声
- 反例：场7不伦瑞克首轮6:1实际平庸、场47狼队热身3:0实际1:1
- 样本：n=3

### 【铁律】主队主场连续零封 + 客队客场哑火 → 主队零封胜
- 画面特征：主队近6主场≥3场零封对手；客队近6客场场均进球<1
- 动作：给主胜，比分从 2:0/3:0 选，不给客队进球
- 正例：场55鹿岛、场181巴拉纳（主场2:0×3零封）
- 反例：场46基尔马诺克主场火力强（3:1/4:1/3:1）我却给了客队1:2——漏看主场画面
- 样本：n=4

### 【铁律】客场火力差分明 → 强的一方赢
- 画面特征：客队近6客场场均进球≥2（客场进球机器）；主队主场近6场输多
- 动作：客胜，比分按客队火力给（见下"比分档位"）
- 正例：场4哈卡（18场36球）1:2、场44德里城1:2
- 样本：n=5

## 二、比分档位（方向定了，给几球）

### 【铁律·最根本】比分=两个对位的直接结果，不许拍脑袋取中间值
- 画面特征（用户8/15点破，数据实锤）：
  - **主队这场进几球 = 主队近6场火力档位 × 客队近6场失球档位**
  - **客队这场进几球 = 客队近6场火力档位 × 主队近6场失球档位**
- 档位：高=场均≥2，中=1~2，低=<1
- 对位结果：
  - 双高（火力高+对方失球高）→ 进 3-5 球
  - 一高一中 → 2-3 球
  - 双低 → 0-1 球
- 反例（我系统性砍半的实锤）：华沙火力2.0+拉多米亚克失2.7，我拍脑袋给2:1，实际5:0；LASK火力2.5给2:0实际4:1；色格拉2.5给1:1实际3:3——看到火力强+对方防守弱，就该给4球5球，不许砍成2球
- 样本：12场主队火力强场次，我平均少给约2球

### 【铁律】防线连续失球 → 对手敢给大比分
- 画面特征：一方近6场场均失球≥2（防线崩盘）
- 动作：对手给 4:1/5:0/0:5/0:4 这种大比分，不保守压到2球
- 反例（10场方向对但进球少给的根）：场17 LASK近6场5场≥3球我给2:0（实4:1）、场18波兹南0:5、场30华沙5:0、场48佛罗伦萨4:1
- 样本：n=10

### 【铁律】双方都无零封+都进球 → 对攻，不猜低比分
- 画面特征：两队近6场都"场场有球、失球也多"
- 动作：给 2:2/3:2/2:3/3:3，绝不给 1:0/0:0
- 正例：场6基尔2:2圣保利、场123利恩、场124兰黑姆3:3
- 反例：场16布莱格我给了2:1（实际3:3）、场42色格拉1:1（实际3:3）
- 样本：n=6

### 【铁律】双闷+一队哑火 → 低比分
- 画面特征：两队近6场大多≤2球，其中一队近3场≤1球
- 动作：1:1/1:0/0:0
- 正例：场15奥迪沃德近3场1球→1:1、场36甘冈布洛涅双弱→1:0
- 样本：n=4

### 【铁律】防守强队 vs 火力强队 → 对冲，别给一边大胜
- 画面特征：一队防守稳（近6场失球少）、一队火力猛（进球多）
- 动作：1:1/1:2/2:1，不给3:0/4:1
- 正例：场29阿尔杰什1:1法鲁尔
- 样本：n=2

## 三、伤停落到方向（看到必须改判断，不当摆设）

### 【铁律】门将伤/停赛 → 该队丢球+1档
- 动作：该队防守判断下调，对手进球预期上调
- 正例：场128威廉二世门将伤→丢球升
- 反例：场53竞技门将+中轴停赛5人，我写进依据却没改方向（实际0:1输）
- 样本：n=3

### 【铁律】锋线核心伤 → 该队进球-1档
- 动作：该队进攻判断下调，对手零封概率上调
- 正例：场159赫塔费双前锋伤(ACL+膝)→阿拉维斯1:0零封
- 样本：n=3

### 【铁律】伤停不能只看"谁伤了"，要看"伤完谁更弱"
- 反例：场52拉塞雷纳伤两锋，我读成"客队弱"，没看主队康塞普西翁主场更弱（实际0:2）
- 样本：n=2

## 四、弃选（看不清就0场）

### 【铁律】杯赛/无情报 → 弃选
- 反例：意杯/爱杯/比乙4场全错或偏（场5/26/32/48）
- 样本：n=4

### 【铁律】样本不足（一方近6场<6场或数据缺失）→ 弃选
- 反例：场289明知客队2场样本还硬出
- 样本：n=3

## 五、可复制的命中机制（81场里6场命中的共性）

1. 跨级别火力差 + 主队闷守 → 客队小胜（场4）
2. 双无零封 + 都进球 → 对攻平局（场6/29）
3. 双闷 + 一队哑火 → 低比分（场15/36）
4. 级别差 + 主队防守波动 → 客队小胜（场44）

**核心一句话**：方向=本场主客场景（主看主、客看客）+ 伤停落到强弱；比分=防线崩给大、双闷给小、对攻给平、对冲别贪——每个比分都从"这队最近真踢出过的档位"里选，不套统一模板。

## 六、诚实边界（画面感的天花板，必须知道）

- 81场精确命中 12/81 = 14.8%，方向 52%——**当前画面感 ≈ 瞎猜**
- 上面的经验每条样本 n 都很小（2-10场），是"假设"不是"铁律"，只能倾向，不能断言
- 真正提升画面感 = 每期复盘继续往这里加正反例，攒到 n≥30 才能升级成"规律"
- 复盘的目的就是这条：**让样本涨上去，让经验越来越硬，让画面感离事实越来越近**
