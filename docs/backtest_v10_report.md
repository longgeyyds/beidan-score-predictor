# v10 模型优化报告：画面驱动 vs 统计池（2026-08-11）

## 背景：用户要求"按实际预测，不套概率"

用户明确否定"无脑猜1:1"式预测，要求每场按实际情况（伤病/状态/天气/攻防画面）给分。
据此设计了 v10 画面驱动模型，并用半年严格赛前模拟验证（2026-02-11~08-11，7,023场，
每场只用赛前数据，只统计下注场次）。

## 实测结果（全部严格防泄漏，只统计下注场次）

| 模型 | 选场 | 比分生成 | 下注 | 命中率 |
|---|---|---|---|---|
| v9e（基准） | 跨年池+大球过滤 | 无脑1:1 | 838 | **13.25%** |
| v10 | 跨年池 | 画面Poisson+联赛先验混合 | 1,043 | 11.51% |
| v10对照 | 跨年池 | 同池无脑1:1 | 1,043 | 12.75% |
| 联赛滚动Top1 | 跨年池 | 各联赛滚动365天Top1 | 1,642 | 11.63% |
| 全比分Top1 | 跨年池 | 各联赛滚动365天Top1(全25项) | 1,642 | 11.45% |
| 性格映射 | 跨年池 | 性格→比分(2025年学习) | — | 跨年不稳定 |

## 关键发现

### 1. 纯画面动态预测跑不赢统计池（诚实结论）
v10 用"期望进球Poisson+联赛滚动先验"生成比分，11.51% < 同池无脑1:1的12.75%。
预测分布里 58.7% 仍是1:1，但被画面"微调"掉的场次（改成1:0/0:1/0:0）全部帮倒忙。

### 2. 性格→比分映射跨年不稳定
| 性格 | 2025年1:1率 | 2026上半年1:1率 | 2026最优比分 |
|---|---|---|---|
| 混合 | 11.6% | 14.5% | 1:1 |
| 双大 | 11.7% | 16.5% | 1:1 |
| 双闷 | 12.2% | **9.1%** | 1:0（18.9%） |
| 主大客闷 | 12.7% | 10.1% | 0:0/1:0 |
| 客大主闷 | 11.6% | 9.3% | 0:1 |

"双闷→1:1"是 skill 里的旧铁律，但2026上半年双闷1:1率只有9.1%——**映射年年变**，
画面信号在6个月窗口内无法稳定预测精确比分。这就是 v4/v5 动态模型（10.08%/8.92%）
失败的根源。

### 3. 唯一稳定的是统计池本身
跨年池（2024+2025连续两年1:1率>12%的联赛）在2026上半年依然成立：池内1:1=12.36%，
加大球过滤后13.25%。**1:1是池内25选1的最可能单一比分——这是各联赛实际比分结构的
统计事实，不是凭空"猜"。**

## 结论：两层模型（最终形态）

```
第1层 统计选场（回测验证，13.25%无情报下限）
  跨年池联赛 + 大球属性过滤（任一方≥60%大球跳过）
  → 决定"哪些场次值得下注"

第2层 情报定比分（实战验证，回测无法模拟）
  赛前情报（伤病/停赛/天气）+ 画面性格
  → 确认或偏离1:1基准：
     情报确认1:1（均势+偏闷+无关键缺阵+天气差）→ 1:1
     情报偏离1:1（单边/核心缺阵/高原/大雨/风格变）→ 按实际给分
     无强情报 → 默认1:1（统计基准，非猜测）
```

**为什么必须两层：**
- 历史数据只有比分，没有伤病/天气——情报层无法回测，这是情报缺口，必须诚实
- 画面动态预测已被证明跨年不稳定（11.51% vs 13.25%）——不能独立生成比分
- 情报是唯一能稳定偏离统计基准的变量（今天的26084实战：4场按情报给了4种比分）

## 对 skill 的修改
1. 动态预测铁律修正：诚实声明画面动态预测跑不赢统计池
2. 预测流程改为两层模型：统计层选场 → 情报层定比分
3. 删除"双闷→1:1"等跨年不稳定的性格映射（2026实测双闷1:1=9.1%）
4. 保留：跨年池 + 大球过滤 + 情报修正决策规则
