# v9 系列回测报告：半年严格赛前模拟（2026-08-11）

## 用户要求（原话要点）
- 以历史为镜，跑半年北单数据，模拟赛前状况（每场只用赛前可得信息）
- 预测，再与实际对比
- **只对比下注的场次**，不对比整个拉取的数据

## 方法
- 预测期：2026-02-11 ~ 2026-08-11，共 7,023 场
- 严格防泄漏：每场只用该场 cutoff 之前的同联赛历史（365天窗口或固定年度）
- 背景参照：预测期全场 1:1 率 11.89%（≈12% 基线），低比分率 52.1%
- 诚实声明：历史 CSV 只有赛果，**无赛前伤病/天气/阵容记录**——本回测为"无情报下限"表现，赛前情报属情报缺口

## 五种策略结果

|---|---|---|---|---|---|

## 核心结论

### 1. 跨年稳定是唯一有效信号
- 只用1年（v9c）或滚动阈值（v9/v9b-C）定池 → 全部 11.4-11.6%，跑不赢基线
- **2024+2025连续两年 1:1 率都>12% 的联赛池**（16个联赛）→ 12.36%
- 再加动态画面过滤（v9e）→ **13.25%**，下注场次从1,642缩到838，命中率反而升

### 2. 动态过滤有效（skill"大球属性"铁律的实证）
- 任一方近8场≥60%大球 → 1:1概率低，跳过804场
- 过滤后：英乙 10.65%→14.29%、K2 12.58%→17.86%、英冠 14.29%→14.67%、南俱杯 15.18%→17.72%
- **大球属性队确实不踢1:1**，这条铁律在半年样本里成立

### 3. 历史规律会失效——这正是赛前情报的价值
跨年池16个联赛中，2026上半年失效的：
| 联赛 | 2024/25年1:1率 | 2026上半年实际 | 死因 |
|---|---|---|---|
| 葡甲 | 17.6%/13.4% | 5.45% | 2025年底起联赛风格系统性变化（逐月1:1率持续走低） |
| 意甲 | 13.3%/12.2% | 8.46% | 同上，2025-11起走低 |
| 足总杯 | 13.2%/15.7% | 0%（n=19） | 样本太少，纯噪声，不该进池 |
| 阿职联 | 17.0%/13.8% | 14.41%（但7-8月崩至3.2%） | 赛季更替期数据打折（skill铁律） |

**结论：没有伤病/天气/战意/新赛季情报，跨年规律在6个月窗口内无法识别"这个联赛这半年风格变了"——13.25% 是纯历史数据的上限，要突破必须靠赛前情报。**

### 4. 稳定贡献者（2026上半年实测>12%的9个联赛）
英联杯21.62%、南俱杯17.72%、K2 17.86%、英冠14.67%、英乙14.29%、阿职联14.12%、意乙13.56%、波兰甲13.56%、罗甲12.86%

## 对实战流程的启示（已写入skill待更新）
1. v8跨年池保留，但**每半年复核一次**：1:1率连续3个月走低的联赛（葡甲/意甲式退化）要从池中剔除
2. 动态大球属性过滤必须保留：任一方近8场≥60%大球 → 1:1不下注
3. 赛季更替期（7-8月）阿职联式崩盘：新赛季数据打折铁律照旧
4. 赛前情报（伤病/天气）是突破13.25%天花板的唯一途径——与用户要求一致
